# Lyriviz

Lyriviz is a Windows desktop lyric visualizer that follows the music you’re already playing. Sing along with synchronized, word-by-word lyrics, or go fullscreen and let the visuals fill the screen.

Choose from 12 animation modes. Constellation sends a comet trail between words, Neon layers glowing lyrics over oversized background text, Code types out each line, and Emoji Roll scrolls words through a curved stack with matching emojis.

## Features

- Native-resolution lyric rendering with a 120 FPS default and adjustable refresh rate
- Custom wallpapers, album-art backgrounds, and a solid black theme
- Optional red beat flash with adjustable sensitivity in Constellation and Emoji Roll
- Fullscreen play/pause, previous-track, and next-track controls
- Per-track lyric timing adjustments and a choice of lyric versions when available
- Local lyric import using timed `.lrc` files or plain-text `.txt` files
- Built-in clock and Pomodoro timer with an editable focus duration

## Download

[**Download the Windows beta**](https://github.com/adityaverma1305/Lyriviz/releases)

Open the newest beta, expand **Assets**, and download `Lyriviz-Windows-x64.zip`.
Extract the ZIP and run `Setup.exe`, or launch `Lyriviz.exe` for portable use.

Requires Windows 10 version 1809 or later, or Windows 11, on an x64 PC
with .NET Framework 4.8 or later. The Apple silicon macOS port is a source preview.
